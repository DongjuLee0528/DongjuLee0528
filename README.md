## 🤖 Selected Projects

### [Wildfire Spot](https://github.com/DongjuLee0528/wildfire-spot)
**AIoT 기반 산불 감지 사족보행 로봇**

- 6종의 산불 데이터셋을 통합·전처리하고 YOLOv10s 기반 화재·연기 감지 모델을 학습했습니다.
- Jetson 기반 AI 추론, 환경 센서, 역기구학 기반 보행 제어를 통합했습니다.
- FastAPI · Spring Boot · React를 연결한 웹 관제 시스템을 구현했습니다.
- 관련 연구를 **제1저자로 학회에서 구두 발표하고 우수논문상을 수상**했습니다.

`YOLOv10s` `Jetson Orin Nano Super` `Python` `FastAPI` `Spring Boot` `React`

### [Arduino Safety Monitor](https://github.com/DongjuLee0528/arduino-safety-monitor)
**엣지 AI 기반 안전모 착용 여부 분류 시스템**

- EfficientNet-B0 기반 안전모 분류 모델을 개발하고 ONNX로 변환해 엣지 추론에 적용했습니다.
- Arduino UNO Q와 App Lab을 활용해 카메라, 초음파 센서 및 이동로봇 하드웨어를 통합했습니다.
- 2인 팀의 리더이자 기술 개발자로 시스템 설계와 구현을 담당했습니다.
- **대림대학교 소프트웨어학부 해커톤 최우수상**을 수상했습니다.

`EfficientNet-B0` `ONNX Runtime` `Arduino UNO Q` `Arduino App Lab`

### [Smart Parking Platform](https://github.com/DongjuLee0528/smart-parking-platform)
**AI 기반 실시간 스마트 주차 플랫폼 · 개발 중**

- CCTV 영상 기반 차량 및 주차 공간 점유 여부 인식을 목표로 개발하고 있습니다.
- AI 추론 서비스, 백엔드, 모바일 앱 및 웹 관리 화면을 연결하는 구조를 설계하고 구현하고 있습니다.

`Python` `FastAPI` `Spring Boot` `Flutter` `React`
